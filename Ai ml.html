A-to-Z Learning Modules

Level 1: Mathematics, Scientific Python & Classical Machine Learning

Linear algebra, calculus, exploratory data analysis, and predictive scikit-learn models.

1. Mathematical Foundations
Matrix operations, eigenvalues, partial derivatives, chain rule, Bayes' theorem, and probability distributions.
2. Scientific Python (NumPy & Pandas)
Array broadcasting, vectorization, dataframe manipulation, missing value imputation, and feature scaling.
3. Supervised & Unsupervised Learning
Linear/Logistic Regression, Decision Trees, Random Forests, XGBoost, K-Means clustering, and PCA.
4. Model Evaluation & Validation
Train/test splits, K-fold cross-validation, Precision, Recall, F1-score, ROC-AUC, and bias-variance tradeoff.

Level 2: Deep Learning, PyTorch, Computer Vision & NLP

Neural architectures, activation functions, backpropagation, and transformer attention mechanisms.

1. Neural Networks & PyTorch Fundamentals
Tensors, computational autograd, custom Dataset/DataLoader, optimizers (AdamW), and loss functions.
2. Computer Vision (CNNs)
Convolutional layers, pooling, transfer learning with ResNet/EfficientNet, and object detection (YOLO).
3. Natural Language Processing (NLP)
Word embeddings, tokenization (BPE), Recurrent Networks (LSTMs), and Transformer encoder/decoder architectures.
4. Model Serving Basics
Wrapping models in FastAPI microservices, handling batch prediction, and containerization via Docker.

Level 3: Generative AI, LLMs, RAG, Fine-Tuning & Production MLOps

Large Language Models, vector indexing, parameter-efficient fine-tuning (LoRA), and automated MLOps pipelines.

1. LLM Fine-Tuning (PEFT / LoRA / QLoRA)
Supervised Fine-Tuning (SFT), quantizing weights to 4-bit/8-bit, and Direct Preference Optimization (DPO).
2. Advanced RAG & Vector Databases
Chunking strategies, dense/hybrid search, rerankers (Cohere), and indexing with Pinecone, Qdrant, or Milvus.
3. High-Throughput Inference (vLLM / Triton)
PagedAttention memory management, continuous batching, model parallel serving, and TensorRT acceleration.
4. Production MLOps & Monitoring
Experiment tracking with MLflow, automated retraining pipelines (Kubeflow), and data drift detection (Evidently AI).
