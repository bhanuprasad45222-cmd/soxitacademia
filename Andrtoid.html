A-to-Z Learning Modules

Level 1: Language Syntax, UI Layouts & Navigation

Core Kotlin / Swift language mastery, declarative view systems, and lifecycle handling.

1. Language Fundamentals
Kotlin (null safety, extension functions, data classes) or Swift (optionals, protocols, structs vs classes).
2. Modern Declarative UI
Jetpack Compose (Modifiers, State, LazyColumns) or SwiftUI (Views, State, Bindings, Lists).
3. App Lifecycles & Navigation
Activities, Fragments, UI ViewControllers, backstack routing, and screen transition arguments.
4. Network API Requests
Consuming REST APIs using Retrofit (Moshi/Gson) on Android or URLSession (Codable) on iOS.

Level 2: Architecture Patterns, Local Storage & Hardware

MVVM architecture, offline database caching, dependency injection, and native sensors.

1. MVVM & Unidirectional Data Flow
ViewModels, StateFlow/SharedFlow in Kotlin, and ObservableObject/@Observable in Swift.
2. Offline-First Data & Caching
Room persistence library (Android) or CoreData / SwiftData (iOS) with schema migrations.
3. Dependency Injection
Structuring decoupled code using Dagger Hilt or Koin for Android, and Swinject/Factory for iOS.
4. Device Hardware & Permissions
Location services (GPS), Camera APIs, Biometric authentication (FaceID/Fingerprint), and Bluetooth.

Level 3: Multi-Module Architecture, Performance & Release

App modularization, memory profiling, automated CI/CD releases, and on-device AI.

1. Multi-Module Architecture
Decoupling features into feature modules, core libraries, and dynamic delivery modules.
2. Profiling & Memory Optimization
Detecting memory leaks (LeakCanary/Xcode Instruments), tracking FPS frame drops, and battery usage.
3. On-Device AI & Push Notifications
Integrating Google ML Kit, Apple CoreML, Firebase Cloud Messaging (FCM), and background sync.
4. Store Publishing & CI/CD
Automated signing, beta distribution via TestFlight/Firebase App Distribution, and Fastlane scripting.
