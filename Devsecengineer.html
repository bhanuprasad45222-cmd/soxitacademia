A-to-Z Learning Modules

Level 1: Secure SDLC & Pipeline Security

Shift-left security, static analysis, and dependency vulnerability scanning.

1. Shift-Left Security Principles
Integrating security early into the Software Development Life Cycle (SDLC).
2. Static Application Security Testing (SAST)
Using SonarQube, Semgrep, and Gitleaks to scan source code and prevent secret leaks.
3. Software Composition Analysis (SCA)
Scanning third-party libraries and npm/pip/maven dependencies for known CVEs.
4. Secure CI/CD Integration
Enforcing security gates in GitHub Actions and GitLab CI pipelines.

Level 2: Secret Management & Container Security

HashiCorp Vault, container vulnerability scanning, and IaC security.

1. Secret Management (HashiCorp Vault)
Dynamic secrets, encryption-as-a-service, and secure credential injection.
2. Container & Image Security
Scanning base images with Trivy or Grype and enforcing distroless containers.
3. Infrastructure as Code (IaC) Security
Scanning Terraform and Kubernetes manifests using Checkov or tfsec.
4. Dynamic Testing (DAST & OWASP ZAP)
Automated penetration testing against staging and running web applications.

Level 3: Zero Trust, Supply Chain & Compliance

Advanced Kubernetes defense, artifact signing, and automated compliance auditing.

1. Software Supply Chain (SBOM & Sigstore)
Generating Software Bills of Materials (SBOM) and cryptographically signing images via Cosign.
2. Kubernetes Security Hardening
Network policies, RBAC, admission controllers (OPA/Gatekeeper), and Falco runtime security.
3. Cloud Security Posture Management (CSPM)
Cloud provider monitoring for misconfigurations, IAM over-permissions, and public S3 buckets.
4. Automated Compliance Auditing
Continuous policy-as-code validation for SOC2, ISO27001, and PCI-DSS standards.
