A-to-Z Learning Modules

Level 1: Manual Testing, STLC, Defect Tracking & SQL

Core testing principles, black-box methodologies, Jira workflows, and database verification.

1. SDLC & STLC Methodologies
Waterfall vs Agile Scrum, sprint ceremonies, test plan creation, and testing life cycles.
2. Test Design Techniques
Boundary Value Analysis (BVA), Equivalence Partitioning (EP), Decision Tables, and State Transition.
3. Defect Management & Jira
Logging clear reproduction steps, setting severity vs priority, and bug lifecycle tracking in Jira.
4. Database Verification (SQL)
SELECT queries, joins, filtering, and validating backend database integrity against UI actions.

Level 2: Web Automation, Page Object Model & API Testing

Writing automated scripts with Playwright/Selenium and validating REST APIs via Postman and RestAssured.

1. Programming for Testers (Java or JS/TS)
Object-oriented programming, methods, collections, exceptions, and clean syntax for tests.
2. UI Automation (Playwright / Selenium)
Locators (CSS/XPath), handling dynamic waits, assertions, alerts, frames, and multi-window testing.
3. Page Object Model (POM) Design
Decoupling page elements from test logic to build maintainable, reusable automation suites.
4. API Testing (Postman & RestAssured)
GET, POST, PUT, DELETE requests, status code assertions, JSON schema validation, and auth tokens.

Level 3: Framework Architecture, CI/CD & Performance Testing

Enterprise SDET frameworks, parallel execution in Docker, CI/CD test gates, and JMeter stress tests.

1. Custom Framework Engineering
Building hybrid data-driven and BDD frameworks (Cucumber / TestNG) with rich HTML reporting (Allure).
2. CI/CD Integration & Test Gates
Triggering automated regression tests on pull requests via GitHub Actions, Jenkins, or GitLab CI.
3. Performance & Load Testing (JMeter / k6)
Simulating concurrent virtual users, tracking response latency, throughput, and error rates under load.
4. Cross-Browser Parallel Grids
Executing distributed test runs across Docker containers and cloud grids (BrowserStack / SauceLabs).
