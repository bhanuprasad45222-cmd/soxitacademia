A-to-Z Learning Modules

Level 1: Server & Database Fundamentals

HTTP protocols, server runtimes, and relational database management.

1. How the Web Works
DNS, TCP/IP, HTTP/HTTPS request-response lifecycle, and status codes.
2. Node.js & Express / Python FastAPI
Asynchronous programming, event loop, routing, and middleware creation.
3. Relational Databases (SQL)
PostgreSQL/MySQL schemas, normalization, foreign keys, and complex SQL queries.
4. Version Control & Testing
Git workflows, environment variables, and unit testing using Jest/PyTest.

Level 2: Advanced APIs, Security & Containerization

Authentication, caching layers, containerization, and message queues.

1. Authentication & Security
JWT, OAuth 2.0, password hashing (bcrypt), CORS, rate limiting, and RBAC.
2. Caching & Background Jobs
Redis caching strategies, session stores, and background queue workers with BullMQ.
3. Containerization (Docker)
Writing Dockerfiles, multi-stage builds, and orchestrating services via Docker Compose.
4. API Documentation & Validation
OpenAPI/Swagger specs, schema validation with Zod or Pydantic.

Level 3: Distributed Systems & Cloud Architecture

Message brokers, Kubernetes, system design, and cloud scaling.

1. Event Streaming & Brokers
Apache Kafka or RabbitMQ event-driven architectures and pub/sub patterns.
2. Kubernetes & CI/CD
K8s pods, deployments, services, and automated GitHub Actions pipelines.
3. System Design & Scaling
Load balancing, horizontal scaling, database sharding, CAP theorem, and CDN strategies.
4. Cloud Infrastructure (AWS/GCP)
IAM policies, serverless functions (Lambda), S3 storage, and VPC configurations.
