A-to-Z Learning Modules

Level 1: Cloud Primitives, Virtual Networks & Storage

Core compute types, private cloud network topology, block/object storage, and security groups.

1. Cloud Computing Foundations
IaaS vs PaaS vs SaaS, availability zones, global regions, edge locations, and shared responsibility models.
2. Virtual Private Clouds (VPC / VNet)
CIDR blocks, public/private subnets, Internet Gateways, NAT Gateways, route tables, and NACLs.
3. Cloud Compute & Storage Hierarchy
Virtual servers (EC2/Azure VMs), auto-scaling groups, object storage (S3), block volumes (EBS), and managed databases (RDS).
4. Identity & Access Management (IAM)
IAM users, roles, instance profiles, policy JSON evaluation logic, MFA enforcement, and access keys.

Level 2: Well-Architected Framework, IaC & Microservices

Designing high availability, declarative automation via Terraform, serverless, and managed Kubernetes.

1. High Availability & Elasticity
Application Load Balancers (ALBs), multi-AZ deployment, health checks, read replicas, and stateless application tiers.
2. Infrastructure as Code (Terraform)
Writing reusable modules, managing remote S3/DynamoDB state backends, workspaces, and policy enforcement via OPA.
3. Serverless & Microservices Stacks
AWS Lambda, API Gateways, EventBridge event buses, and managed container orchestration (Amazon EKS / ECS).
4. Cloud Security & Key Management
AWS KMS envelope encryption, Secrets Manager, AWS WAF, GuardDuty threat detection, and Shield DDoS protection.

Level 3: Multi-Cloud, FinOps, Hybrid Interconnect & DR

Enterprise landing zones, AWS Organizations, Direct Connect, FinOps unit economics, and disaster recovery.

1. Multi-Account Landing Zones
AWS Control Tower, Organizations, Service Control Policies (SCPs), centralized logging, and Transit Gateway hub-and-spoke.
2. Hybrid Connectivity & Direct Connect
AWS Direct Connect, Azure ExpressRoute, IPsec VPN tunnels, BGP routing, and low-latency on-premises interconnects.
3. Cloud FinOps & Cost Governance
Savings Plans, Reserved Instances, Spot allocation strategies, storage tier lifecycle policies, and allocation tagging.
4. Multi-Region Disaster Recovery (DR)
Backup & Restore, Pilot Light, Warm Standby, and Multi-Site Active-Active designs with Route 53 latency routing.
