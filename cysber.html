A-to-Z Learning Modules

Level 1: Mathematics, Cryptography Basics & Circom

Number theory, polynomial commitments, writing R1CS constraints, and generating SNARK proofs.

1. Mathematical Foundations
Finite fields, modular arithmetic, discrete logarithms, and elliptic curve cryptography (ECC).
2. ZK Fundamentals & Arithmetization
Translating computation into polynomials, Rank-1 Constraint Systems (R1CS), and Quadratic Arithmetic Programs (QAP).
3. Circuit Programming (Circom)
Writing zero-knowledge circuits in Circom, compiling constraints, and securely computing the witness.
4. Proof Generation & Verification
Using SnarkJS (Groth16 / Plonk) to generate local proofs, creating a trusted setup, and deploying Solidity verifiers.

Level 2: Advanced DSLs, Halo2, zkEVMs & Rust Provers

Modern proof systems, writing custom constraints in Rust/Halo2, and understanding Layer 2 rollups.

1. Modern ZK DSLs (Noir / Cairo)
Writing circuits in Rust-like syntax (Noir) or Turing-complete STARK languages (Cairo for Starknet).
2. Plonk & Halo2 Frameworks
Understanding universal trusted setups, custom gates, lookup tables, and writing Halo2 circuits in Rust.
3. Rust for Applied Cryptography
Memory safety, multithreading, and optimizing cryptographic primitives to reduce prover bottleneck times.
4. zkEVM Architecture
How zk-Rollups scale Ethereum: proving EVM opcode execution, state roots, and handling data availability.

Level 3: Recursive Proofs, ZKML, Hardware Accel & Security

Proof aggregation, integrating machine learning in circuits, GPU prover acceleration, and formal security audits.

1. Recursive Proofs & Aggregation
Verifying a proof inside another proof to compress transaction data massively before on-chain submission.
2. ZK Machine Learning (ZKML)
Proving that a specific neural network model produced an output without revealing the model weights or input data.
3. Hardware Proving (GPU / FPGA)
Accelerating Multi-Scalar Multiplication (MSM) and Number Theoretic Transforms (NTT) to scale proving networks.
4. Circuit Security & Formal Verification
Identifying under-constrained variables, polynomial identity bugs, and using formal methods to guarantee circuit soundness.
