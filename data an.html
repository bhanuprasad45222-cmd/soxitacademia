A-to-Z Learning Modules

Level 1: Spreadsheet Mastery, SQL & Business Metrics

Data manipulation in Excel, foundational relational database querying, and core business KPIs.

1. Advanced Excel & Google Sheets
XLOOKUP, nested formulas, Pivot Tables, conditional logic, and Power Query transformations.
2. Relational Databases & SQL Basics
SELECT, WHERE, GROUP BY, HAVING, ORDER BY, INNER/LEFT/RIGHT JOINs, and aggregation functions.
3. Data Cleaning & Validation
Detecting duplicates, handling NULL values, normalizing text fields, and standardizing date/time stamps.
4. Business Metrics & KPI Definition
Calculating Customer Acquisition Cost (CAC), Lifetime Value (LTV), Churn Rate, and Monthly Recurring Revenue (MRR).

Level 2: Advanced SQL, Python EDA & BI Dashboards

Complex SQL calculations, Python exploratory data analysis (EDA), and interactive Power BI/Tableau reports.

1. Advanced SQL Techniques
Window functions (ROW_NUMBER, RANK, LEAD, LAG), Common Table Expressions (CTEs), subqueries, and views.
2. Python Data Wrangling (Pandas/NumPy)
DataFrames, merging, groupby aggregations, vectorization, and data profiling using Jupyter Notebooks.
3. Business Intelligence (Power BI & DAX)
Star schema data modeling, calculated columns, DAX measures (CALCULATE, FILTER), and dynamic visual storytelling.
4. Applied Statistics & Hypothesis Testing
Normal distribution, standard deviation, correlation vs causation, p-values, and statistical A/B test analysis.

Level 3: Cloud Warehousing, Analytics Engineering & Strategy

Cloud data platforms, transformation with dbt, pipeline automation, and executive storytelling.

1. Cloud Warehousing (Snowflake / BigQuery)
Querying petabyte-scale data lakes, partitioning, clustering keys, and cost optimization techniques.
2. Analytics Engineering with dbt
Transforming raw warehouse data into clean dimensional models (fact and dimension tables) via dbt models.
3. Predictive Analytics & Regression
Linear regression, logistic modeling, cohort analysis, and trend forecasting using Scikit-Learn.
4. Executive Storytelling & Governance
Data cataloging, documentation, building executive summary dashboards, and pitching ROI-driven strategies.
