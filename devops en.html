A-to-Z Learning Modules

Level 1: Linux, Version Control & Containerization

Operating system administration, shell scripting, and container packaging.

1. Linux Administration & Shell
File permissions, process control, networking commands, and Bash scripting.
2. Version Control (Git & GitHub)
Branching workflows, resolving merge conflicts, and GitHub collaboration.
3. Containerization (Docker)
Writing Dockerfiles, managing volumes, networking, and Docker Compose multi-container setups.
4. Basic Networking & Protocols
TCP/IP, DNS, TCP/UDP ports, TLS/SSL certificates, and reverse proxies (Nginx).

Level 2: Cloud Platforms, IaC & CI/CD Pipelines

Cloud provider provisioning, Infrastructure as Code, and automated build pipelines.

1. Cloud Fundamentals (AWS / GCP)
IAM, VPCs, EC2 instances, S3 storage, and serverless architectures.
2. Infrastructure as Code (Terraform)
Writing reusable Terraform modules, state management, and remote backends.
3. CI/CD Automation (GitHub Actions)
Building automated test, build, and deployment pipelines for cloud environments.
4. Configuration Management (Ansible)
Writing playbooks for server configuration, software provisioning, and patch management.

Level 3: Kubernetes, GitOps & Observability

Advanced container orchestration, GitOps delivery, and enterprise monitoring.

1. Kubernetes (K8s) & Helm
Pods, deployments, services, ingress controllers, and Helm chart package management.
2. GitOps & Continuous Delivery
ArgoCD implementation for declarative Kubernetes cluster state synchronization.
3. Observability & Monitoring
Prometheus metrics collection, Grafana dashboards, and centralized log aggregation.
4. DevSecOps & Cloud Security
Container vulnerability scanning, secret management (Vault), and compliance automation.
