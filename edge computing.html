A-to-Z Learning Modules

Level 1: ReAct Reasoning, Tool Calling & Structured Outputs

The core cognitive loop: Thought, Action, Observation, and returning validated JSON data structures.

1. The ReAct Pattern
Implementing the fundamental loop: reasoning through thoughts, selecting actions, inspecting observations, and concluding.
2. Function & Tool Calling
Binding Python functions to LLMs using JSON Schema/Pydantic, handling argument generation, and executing tools.
3. Structured Data Validation
Ensuring agent outputs strictly follow type-safe Pydantic models, handling tool call parsing errors, and retries.
4. Simple Agent Loops in Python
Writing basic agent while-loops with step termination limits, token tracking, and emergency exit conditions.

Level 2: LangGraph State Machines, MCP, Memory & Sandboxes

Replacing linear chains with cyclical state graphs, standardized tool servers, and isolated execution.

1. LangGraph State Machine Engineering
Defining TypedDict State schemas, stateful nodes, conditional edges, cycle loops, and persistent SQLite checkpointers.
2. Model Context Protocol (Anthropic MCP)
Building and consuming standardized MCP servers to expose files, databases, and APIs to agents seamlessly.
3. Multi-Tier Agent Memory (Mem0)
Short-term thread memory, long-term semantic profile recall, and episodic memory extraction across user sessions.
4. Sandboxed Code Execution (E2B)
Spawning isolated cloud micro-VMs where agents can safely write, run, and debug Python scripts and shell commands.

Level 3: Multi-Agent Swarms, Self-Correction, HITL & Observability

Hierarchical supervisor teams, Human-in-the-Loop approval breakpoints, and enterprise production tracing.

1. Multi-Agent Swarms (CrewAI & LangGraph)
Hierarchical topologies with designated lead supervisor agents routing sub-tasks to specialized worker agents.
2. Self-Reflection & Reflexion Loops
Adding automated critic/evaluator nodes that inspect agent output, generate critique feedback, and trigger re-execution.
3. Human-in-the-Loop (HITL) Checkpoints
Pausing graph state before sensitive actions, rendering review UIs, and resuming execution upon human approval.
4. Observability & Tracing (LangSmith)
Capturing step-by-step agent traces, latency bottlenecks, token costs, hallucinated tool calls, and regression datasets.
