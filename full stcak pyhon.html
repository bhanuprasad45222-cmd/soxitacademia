A-to-Z Learning Modules

Level 1: Python Core, Web UI & Django Fundamentals

Python syntax, OOP, relational databases, and server-rendered web applications.

1. Python Fundamentals & OOP
Data types, functions, control flow, list comprehensions, classes, inheritance, and virtual environments.
2. Web UI Basics (HTML/CSS/JS)
Semantic HTML, Flexbox, CSS styling, DOM manipulation, and JavaScript fetch calls.
3. Django Web Framework
MVT pattern, URL dispatching, Django views, templates, forms, and administrative panel.
4. Relational Data & SQL
PostgreSQL/SQLite, Django ORM models, migrations, relationships, and queries.

Level 2: RESTful APIs, React & Async Background Tasks

FastAPI, Django REST Framework, React integration, and task workers.

1. Django REST Framework & FastAPI
Serializers, Pydantic models, dependency injection, CRUD endpoints, and OpenAPI docs.
2. Modern Frontend (React)
React hooks, state management, Axios API consumption, and Tailwind CSS layouts.
3. Authentication & Security
JWT token lifecycles, OAuth 2.0 social logins, password hashing, and CORS headers.
4. Background Jobs & Caching
Celery task queues, Redis brokers, scheduled cron tasks, and in-memory query caching.

Level 3: Microservices, System Design & Cloud Scale

Asynchronous I/O, Docker containerization, CI/CD pipelines, and cloud hosting.

1. High-Performance Async (asyncio)
Event loops, coroutines, async database drivers (asyncpg), and WebSocket streaming.
2. Containerization (Docker)
Dockerfiles for Python, multi-container stacks via Docker Compose (Web, DB, Redis, Celery).
3. CI/CD & Automated Testing
Pytest test suites, coverage reports, and automated deployment via GitHub Actions.
4. Cloud Deployment & System Design
Nginx reverse proxies, Gunicorn/Uvicorn workers, AWS/Render hosting, and database indexing.
