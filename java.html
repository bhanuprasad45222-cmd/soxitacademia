A-to-Z Learning Modules

Level 1: Core Java & Web Fundamentals

Java programming concepts, OOP, foundational frontend, and database basics.

1. Core Java & OOP
Classes, interfaces, inheritance, Collections framework, Exception handling, and Java 8+ features.
2. Web UI Fundamentals
HTML5, CSS3, DOM manipulation, and modern JavaScript (ES6+).
3. Relational Databases (SQL)
MySQL/PostgreSQL basics, CRUD operations, joins, and JDBC concepts.
4. Tools & Build Systems
Git version control, Maven/Gradle build tools, and IDEs (IntelliJ/Eclipse).

Level 2: Spring Boot, ORM & Modern Frontend

Enterprise backend frameworks, data persistence, and SPA integration.

1. Spring Boot & REST APIs
Dependency Injection, REST Controllers, routing, validation, and Exception handling.
2. Hibernate & Spring Data JPA
Entity mapping, repositories, complex queries, transactions, and connection pooling.
3. Frontend Frameworks
Building Single Page Applications (SPAs) with Angular (TypeScript) or React.js.
4. Spring Security & Auth
Implementing stateless authentication using JWT, OAuth2, and role-based access.

Level 3: Microservices, DevOps & System Design

Distributed Java architectures, cloud deployment, and container orchestration.

1. Microservices Architecture
Spring Cloud, Service Discovery (Eureka), API Gateways, and Circuit Breakers (Resilience4j).
2. Event-Driven Systems
Asynchronous messaging and event streaming using Apache Kafka or RabbitMQ.
3. Docker & Kubernetes
Containerizing Spring Boot apps and orchestrating deployments with Kubernetes.
4. CI/CD & Cloud Hosting
Jenkins/GitLab CI pipelines and deploying Java workloads to AWS (EC2/ECS/EKS).
