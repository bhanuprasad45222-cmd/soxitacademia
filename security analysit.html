A-to-Z Learning Modules

Level 1: Networking, OS Fundamentals & SIEM Triage

Network traffic analysis, operating system logging, and Tier 1 alert handling.

1. Networking & Security Protocols
OSI model, TCP/UDP handshakes, DNS tunneling, HTTP/S traffic, and firewall filtering.
2. Windows & Linux Operating Systems
Windows Registry, process trees, service management, and Linux permission structures.
3. SIEM Fundamentals & Log Analysis
Splunk / ELK Stack log ingestion, parsing, and triaging security alerts.
4. Ticketing & Incident Lifecycle
ITIL incident management, defining false positives versus true positive threats.

Level 2: Incident Response, EDR & Packet Analysis

Endpoint investigation, memory dumps, network forensics, and containment.

1. Endpoint Detection & Response (EDR)
Using CrowdStrike or Microsoft Defender to hunt suspicious process ancestry and isolate hosts.
2. Network Packet Forensics
Deep packet inspection using Wireshark to extract malicious payloads and identify C2 beacons.
3. Malware Triage & Sandboxing
Safe static and dynamic analysis of suspicious executables and scripts.
4. Incident Containment & Eradication
Executing containment playbooks, revoking compromised credentials, and patching vulnerabilities.

Level 3: Threat Hunting, Detection Engineering & DFIR

Advanced threat intelligence, Sigma rules, YARA, and deep digital forensics.

1. MITRE ATT&CK Framework
Mapping adversary tactics, techniques, and procedures (TTPs) to defensive controls.
2. Detection Engineering (Sigma & YARA)
Writing custom SIEM detection rules and YARA signatures for malware file matching.
3. Proactive Threat Hunting
Formulating hunting hypotheses based on emerging threat actor campaigns.
4. Digital Forensics & Incident Response (DFIR)
RAM memory dumping (Volatility), disk imaging, and chain of custody reporting.
