A-to-Z Learning Modules

Level 1: Networking, OS Hardening & AppSec Basics

Network defense, OS security configurations, and web vulnerability assessment.

1. Secure Networking & Firewalls
TCP/IP filtering, VPNs, VLAN segmentation, and perimeter defense configurations.
2. Operating System Hardening
CIS benchmarks for Linux and Windows, least privilege policies, and patch management.
3. Web Application Security (OWASP Top 10)
Understanding injection, XSS, CSRF, broken authentication, and secure coding principles.
4. Vulnerability Assessment Tools
Using Burp Suite, Nmap, and Nessus to scan and evaluate application posture.

Level 2: Threat Modeling, IAM & Cryptography

STRIDE methodology, OAuth/OIDC federation, and Public Key Infrastructure.

1. Threat Modeling (STRIDE / PASTA)
Analyzing software architectures during design phases to identify and mitigate risks early.
2. Identity & Access Management (IAM)
OAuth 2.0 grant types, OpenID Connect, JWT validation, and multi-factor authentication (MFA).
3. Cryptography & PKI
Symmetric/asymmetric encryption, hashing algorithms, TLS certificate lifecycles, and key storage.
4. API & Microservices Security
Securing REST and GraphQL APIs against unauthorized access, parameter tampering, and abuse.

Level 3: Zero Trust Architecture & Cloud Security

Zero trust network design, cloud security posture management, and resilient multi-tenant architecture.

1. Zero Trust Architecture (ZTNA)
Implementing continuous verification, microsegmentation, and device posture checking.
2. Cloud Security Architecture (AWS/Azure)
Secure VPC design, IAM boundary policies, KMS encryption, and guardrails automation.
3. Container & Kubernetes Hardening
Pod security standards, service mesh encryption (Istio), and runtime isolation.
4. Enterprise Risk & Compliance
Designing systems meeting SOC2, ISO27001, and GDPR technical control requirements.
