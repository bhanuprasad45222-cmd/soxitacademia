A-to-Z Learning Modules

Level 1: Networking, Identity Fundamentals & Perimeter Erosion

Understanding why legacy perimeter models fail, foundational authentication, and endpoint integrity.

1. Zero-Trust Philosophy & NIST 800-207
The core axioms: continuous verification, assume breach, least-privilege, and explicitly validating all sessions.
2. Identity as the New Perimeter
Single Sign-On (SSO), SAML, OIDC, FIDO2 WebAuthn hardware keys, and passwordless authentication standards.
3. Device Health & Context Attestation
MDM profiling, checking OS patches, disk encryption, EDR presence, and location telemetry before granting access.
4. Network Protocols & Cryptography
TLS 1.3 handshake mechanics, certificates, asymmetric encryption, and evaluating VPN vulnerabilities.

Level 2: ZTNA, Policy-as-Code & Network Microsegmentation

Replacing VPNs with ZTNA, writing fine-grained authorization policies in Rego, and isolating east-west traffic.

1. ZTNA & Software-Defined Perimeter (SDP)
Implementing dark cloud principles where services are completely hidden from the public internet until authenticated.
2. Policy-as-Code (OPA & Rego)
Decoupling policy from application code: authoring declarative access rules for APIs and cloud infrastructures.
3. Network Microsegmentation & eBPF
Using Cilium or Illumio to segment container workloads and virtual machines, blocking lateral attacker pivot paths.
4. Privileged Access Management (PAM)
Just-in-Time (JIT) access, ephemeral SSH/RDP session recording, and eliminating permanent admin privileges.

Level 3: Workload Identities, SASE & Enterprise Autonomous Defense

SPIFFE/SPIRE workload attestation, SASE convergence, automated blast-radius containment, and CARTA.

1. Workload Identity (SPIFFE / SPIRE)
Issuing short-lived cryptographic identities to microservices, enabling mutual TLS (mTLS) across multi-cloud environments.
2. Enterprise SASE & Security Service Edge (SSE)
Unifying CASB, SWG, and ZTNA into a cloud-native security edge architecture for distributed workforces.
3. Continuous Adaptive Risk Assessment (CARTA)
Real-time behavior evaluation: terminating active tokens dynamically if device posture degrades during a session.
4. Automated Incident Containment
Engineering SOAR workflows to quarantine hosts, revoke credentials, and shrink blast radiuses in seconds upon alert.
